# Golden Hour Photography

Fictional, static wedding-photographer portfolio for testing the I Do! live importer. All people, stories, contacts, and images are demonstration material. No enquiries or bookings are accepted.

Public source URL: https://golden-hour-photography-portfolio.safeamber12.chatgpt.site/

## Independent publishing

This is a separate PUBLIC Sites project (`appgprj_6aee24c79f2c8191867c107e6666864b`). I Do! remains a separate private project. Changes to this folder do not automatically deploy either site.

1. Edit visible copy in `build.mjs`, or styling in `dist/style.css`.
2. Run `node build.mjs` and `node tests/coverage.test.mjs` from this folder.
3. Open the registered Golden Hour project using the Sites source workflow, with a write credential scoped to that project. Package and push its exact source, then save and deploy its version using the public Sites deployment operation. Never use I Do!'s project ID or source credentials here.
4. In I Do!, select Photographer and use the public URL. Read fresh website starts a new retrieval/extraction request; a retry retains the existing request identifier.

The deployment serves only `dist/`. All substantive copy is ordinary visible HTML; there is no intake JSON, vendor fixture, hidden answer map, or JavaScript requirement. `tests/coverage.json` is a QA-only map and must never be supplied to the importer. Six original AI-generated images are included as optimized JPEGs.
